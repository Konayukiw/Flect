Flect is a native Windows app that integrates into Explorer as a shell extension. Built with C++ / .NET, it edits files locally, so nothing is ever sent to a server.

Your Originals Are Safe

Results are always written out as new files - nothing is overwritten or deleted. If a name is already taken, a suffix like "(1)" is added.

Select hundreds of files at once. The whole selection is handled in a single run - no manual, one-by-one work.

features

The Right Menu, Wherever You Need It

For every file type, only the operations it actually needs show up in the right-click menu.

Image

Images: From Resizing to Background Removal

  • Resize - by ratio or exact pixels, with preset sizes selectable in one click from the menu.
  • Compress - down to a target size while keeping quality as high as possible.
  • Rotate - to any angle. Corners become transparent, or are filled with a chosen color for formats without alpha.
  • Convert - between PNG, JPG, WEBP, HEIC, ICO, GIF, and SVG.
  • OCR - extract text from images, then save or copy it.
  • Metadata removal - strip EXIF, GPS location, comments, and camera info for safe sharing on social media.
  • Background removal - chroma-key out a single color such as a green screen.
Video & Audio

Video: Cuts Without Re-encoding

  • Trim - the cut finishes the moment you click. No re-encoding by default, so exports are fast.
  • Thumbnail - export any single frame as a PNG or JPG image.
  • Compress - automatically adjust to a target size with minimal quality or FPS loss.
  • Resize / rotate - by ratio or exact pixels, with presets one click away in the menu.
  • Convert - between MP4, MOV, MKV, M4A, AVI, WEBM, FLV, and GIF.
  • Audio extraction - pull the audio track out of any video.
  • Quality and speed - switch codecs (H.264 / H.265 / VP9 / AV1) and hardware encoding (NVENC / Quick Sync / AMF) in settings.
Folder

Folders: All the Dirty Work of Tidying Up

  • Duplicate removal - delete files that match by size, hash, and bytes in bulk.
  • Empty folder cleanup - remove accumulated empty folders with one click.
  • Tree view - visualize the folder structure to make organizing easier.
  • Batch rename - rename all files inside a folder at once.
  • Analyze - visualize which files take up space and where duplicates hide.
  • Compress - bundle the folder into a ZIP / 7z / TAR / tar.gz archive.
  • Extract - unpack ZIP / 7z / TAR / tar.gz / RAR into a new folder.
Text & Documents

Text: CSV, JSON, PDF

  • PDF - preview, merge multiple files, and export to PNG / JPG / TXT.
  • Text - convert file types, change character encodings (UTF-8 / UTF-16 / Shift_JIS...), and switch line endings (CRLF / LF).
  • JSON - beautify and reorder keys with rules.
  • JAR - decompile in one click and export the source code to a new folder.

how it works

How It Works

A C++ shell extension renders the menu inside Explorer, while a .NET application handles the actual work.

C++

Shell Extension

The front end that renders the right-click menu inside Explorer. As a native Windows IContextMenu handler it stays lightweight and reads the selected file's info on the spot.

  • Runs as a standard Explorer menu
  • Dynamically builds menus per file type
  • Sits under "Show more options" on Windows 11
.NET

Processing

Handles the real work - conversion, compression, analysis - and settings management. Invoked from the shell extension via a launcher, it reports progress and results back.

  • FFmpeg, ImageMagick, PDFium, and more bundled
  • Shows a progress window; on failure or cancel, aborts and automatically deletes files being created
  • Settings are stored in a JSON file under %APPDATA%

Installs in 3 Steps

Download, run, and start right-clicking.

  1. 01

    Get the Installer

    Download the latest Flect-Setup.exe from Releases. If .NET 10 Desktop Runtime is missing, the setup detects it and guides you through.

  2. 02

    Run the Setup

    Just run the downloaded installer - every conversion and analysis engine is bundled with it. Explorer may restart during setup; that's normal.

  3. 03

    Try a Right Click

    Right-click a file and open "Show more options" to find the Flect menu. Tune menu items and compression presets in the settings app.

    Run reg add "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32" /f /ve in Command Prompt and restart Explorer to show Flect in the first-level context menu. To undo, delete the registry key and restart.

System Requirements

  • 64-bit Windows 11 / Windows 10
  • .NET 10 Desktop Runtime (the installer will guide you if it's missing)
  • HEVC Video Extensions is only required for HEIC export: Microsoft Store.
  • JDK / JRE is only needed for JAR decompilation.
  • A Windows language pack is only needed for OCR.

Engines for images, video, PDF, and decompilation are all bundled. No extra downloads, no server transfers - everything runs locally.

faq

Frequently Asked Questions

The Flect menu is buried under "Show more options"

Switch the context menu back to the Windows 10 style and Flect appears directly in it. Run reg add "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32" /f /ve in Command Prompt and restart Explorer. This affects the whole system, so delete the key if you'd rather not keep it.

Where do converted files go?

As new files next to the originals - nothing is modified or deleted. If a name already exists, a sequential number like (1) is added.

Can I restore deleted files?

By default, deleted files go to the Recycle Bin, so yes. Only if you switch to permanent deletion in settings can they no longer be restored.

Why does "to HEIC" fail?

HEIC export requires Microsoft's HEVC Video Extensions (reading doesn't). Flect can't bundle this codec, so it uses Windows' WIC encoder for HEIC export only.

OCR warns me about a missing language

Flect uses Windows' built-in OCR. Check installed languages under Settings → OCR, where adding a language pack is also guided. Language packs can be large, and adding one may require administrator rights.

Trimmed video starts a bit before the marked point

That's the result of not re-encoding. Video is stored by keyframes, and cutting by copy has to rewind to the nearest keyframe, which can shift the start by a few seconds. For precise cuts, switch Settings → Video → Trim to "Match the marked position" - it trades a bit of speed.

Aaah! Too many items in the right-click menu!

Open the settings app and uncheck the items you want to hide under General → Right-Click Menu Items.

I want to uninstall

Uninstall like any other app from Windows Settings → Apps.

Where are settings stored?

In %APPDATA%\Flect\settings.json. Some values needed by the Explorer menu itself are also stored in HKCU\Software\Flect. "Reset settings" clears both while keeping shell registration and learned encoder results.

If your question isn't answered here, report it on GitHub Issues - attaching the activity log helps a lot.
