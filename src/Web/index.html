demo

デモを試す

デスクトップにあるファイルやフォルダを右クリックしてみてください。Flect のメニューが開きます。
ファイル名をダブルクリックすると名前の変更も試せます。

デスクトップ

←→↑

右クリックで Flect メニューを開けます。Esc キーで閉じます。

処理を開始します
すべての処理は PC 上で実行されます。元のファイルは一切変更されません。

「変換ツールを探す時間」と
「ウィンドウを行き来する手間」。
その両方を、右クリック 1 回で削減します。

Flect はシェル拡張としてエクスプローラーに統合される、Windows ネイティブのソフトウェアです。C++ / .NET で動作し、ファイルはローカル環境下で編集されるためサーバーに転送されません。

元ファイルを守る

処理結果は必ず新しいファイルとして書き出されます。上書きも消去もされません。名前が重複するときは「(1)」などの接尾辞がつきます。

まとめて編集

ファイルは何百個でも一括で選択できます。処理は選択全体に対して 1 回の実行で走ります - 1 個ずつ手動で行うなんてことはありません。

オフライン処理

外部の依存ファイルもすべてインストーラーが自動でダウンロードします。アップロードもログ送信もなく、ファイルはどこにも送信されません。

features

必要な場所に、必要なメニュー

ファイルの種類ごとに、そのファイルに必要な操作だけが右クリックメニューに並びます。

画像

画像：リサイズから背景透過まで

  • リサイズ — 比率指定または絶対ピクセル指定。メニューから指定サイズをワンクリックで選べます。
  • 圧縮 — 指定サイズまで圧縮します。画質は可能な限り維持されます。
  • 回転 — 任意の角度。角は透過、アルファ非対応形式の場合指定色で塗りつぶされます。
  • 変換 — PNG / JPG / WEBP / HEIC / ICO / GIF / SVG 間の変換が可能です。
  • OCR — 画像から文字を読み取り、保存やコピーができます。
  • メタデータ削除 — EXIF・GPS 位置情報・コメント・カメラ情報を削除し、安全なSNS投稿を可能に。
  • 背景削除 — クロマキーでグリーンバックなど特定の 1 色を透過できます。
動画 & 音声

動画：再エンコードなしの切り抜き

  • トリム — クリックした瞬間に切り出し完了。デフォルトでは再エンコードを行わないため高速で書き出しが可能です。
  • サムネイル — 動画の好きな 1 フレームを PNG / JPG の画像として書き出せます。
  • 圧縮 — 目標サイズまで自動で調整します。画質やFPSの低下は最小限に抑えたまま圧縮されます。
  • リサイズ / 回転 — 比率指定または絶対ピクセル指定。メニューから指定サイズをワンクリックで選べます。
  • 変換 — MP4 / MOV / MKV / M4A / AVI / WEBM / FLV / GIF 間の変換が可能です。
  • 音声抽出 — 動画から音声ファイルの抽出ができます。
  • 品質と速度 — コーデック (H.264 / H.265 / VP9 / AV1) やハードウェアエンコード (NVENC / Quick Sync / AMF) は設定で切り替え可能。
フォルダ

フォルダ：整理の汚れ仕事を一手に

  • 重複削除 — サイズ/ハッシュ/バイトが一致する重複ファイルをまとめて削除できます。
  • 空フォルダ削除 — 溜め込んだ空フォルダを 1 クリックで削除できます。
  • ツリー表示 — フォルダ構成を視覚的に表示し、整理が容易になります。
  • 一括リネーム — フォルダ内のファイルをまとめて名前変更できます。
  • 解析 — 容量を圧迫しているファイルや重複ファイルをまとめて視覚化します。
  • 圧縮 — フォルダを ZIP / 7z / TAR / tar.gz アーカイブにまとめます。
  • 展開 — ZIP / 7z / TAR / tar.gz / RAR を新しいフォルダに展開します。
テキスト & ドキュメント

テキスト：CSV、JSON、PDF

  • PDF — プレビュー、複数ファイルの結合、PNG / JPG / TXT への書き出しに対応。
  • テキスト — ファイルタイプの変換、文字コード (UTF-8 / UTF-16 / Shift_JIS…) の変更、改行コード (CRLF / LF) の切替。
  • JSON — 整形、キーの並べ替えをルール付きで実行。
  • JAR — ワンクリックで逆コンパイルし、ソースコードを新規フォルダに書き出します。

how it works

動作の仕組み

エクスプローラーにメニューを表示する C++ シェル拡張と、実際の処理を担う .NET アプリケーションが連携しています。

C++

シェル拡張

エクスプローラーの中で右クリックメニューを表示するフロント担当。 Windows ネイティブ IContextMenu ハンドラなので動作が軽く、選んだファイルの情報をその場で的確に読み取れます。

  • エクスプローラーの標準メニューとして動作
  • ファイル種別に応じたメニューを動的生成
  • Windows 11 では「その他のオプションを表示」配下に配置されます
.NET

処理

変換・圧縮・解析などの実処理と設定管理を担います。シェル拡張からはランチャー経由で呼び出され、進捗と結果を返します。

  • FFmpeg / ImageMagick / PDFium などが同梱
  • 進捗ウィンドウを表示し、失敗・キャンセル時はファイル処理をキャンセルし自動で削除します。
  • 設定は %APPDATA% 配下の JSON ファイルで管理されています。
setup

インストールは 3 ステップ

ダウンロードして、実行して、あとは右クリックするだけ。

  1. 01

    インストーラーを入手

    Releases から最新の Flect-Setup.exe をダウンロードします。.NET 10 Desktop Runtime がインストールされていない場合、セットアップが自動で検出して案内します。

  2. 02

    セットアップを実行

    ダウンロードしたインストーラーを実行するだけです。すべての変換・解析エンジンはインストーラーに同梱されています。セットアップ時にエクスプローラーが再起動することがありますが、これは正常な動作です。

  3. 03

    右クリックしてみる

    ファイルを右クリックして「その他のオプションを表示」を開くと、 Flect のメニューが表示されます。設定アプリでメニュー項目や圧縮プリセットを好みに調整できます。

    コマンドプロンプトでreg add "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32" /f /ve を実行してエクスプローラーを再起動すると、Flect を第一階層の右クリックメニューに表示することもできます。元に戻すにはレジストリを削除して再起動します。

動作環境

  • 64bit Windows 11 / Windows 10
  • .NET 10 Desktop Runtime（無い場合はセットアップが案内）
  • HEIC の書き出しを行う場合のみ HEVC Video Extensions が必要です。
  • JAR の逆コンパイルのみ JDK / JRE が必要です。
  • OCR のみ Windows 言語パックが必要です。

画像・動画・PDF・逆コンパイルのエンジンはすべて同梱されています。追加ダウンロードなし、ファイルはサーバーに転送されず、ローカルで動作します。

faq

よくある質問

Flect メニューが「その他のオプションを表示」の中にあり開きづらい

右クリックメニューを Windows 10 仕様の形式に戻すことで右クリックメニューに直接表示可能です。コマンドプロンプトでreg add "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32" /f /ve を実行し、エクスプローラーを再起動します。これはシステム全体に影響するため、好みでない場合はレジストリを削除して元に戻してください。

変換後のファイルはどこに作成される？

新しいファイルとして作成されます。元ファイルは変更も削除もされません。名前が重複する場合は (1) のように連番を付けます。

削除したファイルは復元できる？

デフォルトでは削除されたファイルはごみ箱に移動するので、復元できます。設定から完全に削除する方式に切り替えた場合のみ、復元できません。

「to HEIC」が失敗するのはなぜ？

HEIC の書き出しには Microsoft の HEVC Video Extensions が必要です(読み込みは不要)。Flect はこのコーデックを同梱できないため、HEIC 書き出し時のみ WIC 経由で Windows 側のエンコーダーを使用します。

OCR で「言語の認識機能がない」と警告される

Flect は Windows が搭載する文字認識機能を使用しています。設定 → OCR でインストール済みの言語が確認でき、言語パックの追加も案内されます。言語パックは容量が大きいことがあり、追加には管理者権限が必要です。

トリムした動画が、マークした位置より少し前から始まる

再エンコードしない影響です。映像はキーフレームごとに保存されており、コピーだけで切るとキーフレームの開始点まで遡る必要があるため、数秒のずれが生じることがあります。正確な切り抜きを行いたい場合は、設定 → ビデオ → トリムで「指定した位置に合わせる」に切り替えてください。この場合、処理速度が低下します。

ンァーッ！右クリックメニューの項目が多すぎます！

設定アプリの 一般 → 右クリックメニュー項目 で、非表示にしたい項目のチェックを外してください。

アンインストールしたい

Windows の 設定 → アプリ から、他のアプリと同じようにアンインストールできます。

設定はどこに保存されますか？

%APPDATA%\Flect\settings.json に保存されます。エクスプローラーメニュー自体が必要とする値の一部は HKCU\Software\Flect にも保存されます。「設定をリセット」すると両方がクリアされ、シェル登録と学習済みエンコーダー結果はそのまま残ります。
